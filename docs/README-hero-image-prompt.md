# README Hero Image Prompt

The built-in image-generation service was unavailable when the README hero was updated. This prompt is retained so a polished advertising hero can be generated later without reintroducing private browsing data.

README 首屏更新时，内置图像生成服务不可用。保留此 Prompt，便于后续直接生成更完整的宣传 Hero，同时避免重新引入任何私有浏览数据。

```text
Use case: ads-marketing
Asset type: extra-wide GitHub README hero banner for an open-source Chrome extension

Primary request:
Create a premium software-launch hero that communicates: “Arc's active development has stopped, but your Arc workflow can continue in Chrome.” The product is “Side Bar for Arc Users — Arc Style”, a Chrome extension whose core goal is to reproduce Arc's tab-management behavior and visual language as closely as Chrome extensions allow.

Input images:
- Image 1: a real Arc screenshot using a public Demo Space. Treat it as the visual and interaction reference.
- Image 2: a real Chrome screenshot showing Side Bar for Arc Users with the same public Demo Space. Preserve the actual extension UI and Chrome Side Panel frame.

Scene/backdrop:
A deep midnight-navy to indigo gradient with a restrained lavender glow, subtle glass reflections, fine film grain, and realistic depth. Premium developer-tool launch aesthetic; confident and modern, not cyberpunk.

Subject:
Two large, floating browser-sidebar panels shown side by side. Arc is on the left; Side Bar for Arc Users inside Chrome is on the right. Both panels visibly share the same information architecture: Favorites grid, one named Space, pinned pages, an expanded folder, an active item, ordinary tabs, and bottom Space navigation. A subtle luminous bridge between the panels suggests continuity rather than imitation.

Composition/framing:
16:9, ideally 1920×1080 or 2400×1350. Keep both UI panels large and readable at GitHub README width. Use very slight perspective only; UI geometry must remain credible. Leave clean negative space in the upper center for optional headline placement, but do not render the headline inside the image.

Lighting/mood:
Soft violet rim light, natural glass reflections, realistic shadows, reassuring and future-facing. The right-hand extension panel should feel like the continuation of the left-hand Arc panel.

Color palette:
Arc lavender, indigo, midnight navy, soft white, restrained cyan accents.

Text:
No generated slogans, captions, labels, or logos. Preserve only text already visible inside the supplied real UI screenshots. Do not invent interface text.

Constraints:
- Preserve the real hierarchy and controls from the input screenshots.
- Use public-demo content only: Google, YouTube, ChatGPT, GitHub, MDN, and Cloudflare are acceptable.
- Do not show company-internal domains, documents, user data, account details, or confidential information.
- Do not invent unsupported extension features.
- Do not imply that the extension can restyle Chrome's native address bar, horizontal tab strip, or Side Panel host header.
- No people, mascots, watermarks, or decorative browser logos.
- Keep icons and interface text crisp; if exact UI preservation is not possible, use the supplied screenshots as unmodified composited panels rather than redrawing them.

Avoid:
Illegible fake UI text, warped icons, duplicated controls, excessive neon, crowded composition, tiny unreadable panels, generic vertical-tabs UI, fake testimonials, comparison checkmarks, and any private or corporate browsing data.
```

Recommended headline to place in README text rather than inside the image:

> **Arc's active development has stopped. Your Arc workflow doesn't have to.**
>
> **Arc 的积极开发已经停止，但你已经习惯的 Arc 工作流不必跟着消失。**
